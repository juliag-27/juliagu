# Julia Gu Portfolio

A responsive, single-page personal portfolio built from Julia Gu's resume.

## Run locally

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Deploy

This is a static website and can be deployed directly to:
- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages

## Customize

- Main content: `index.html`
- Styling: `styles.css`
- Scroll reveal / footer year: `script.js`
